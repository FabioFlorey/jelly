What you can build

Put your AI to work on the real web.

From research to action, Jelly gives AI agents the browser capabilities to get things done. Modern websites are interactive, dynamic, and often impossible to navigate through simple web requests. Jelly gives AI agents access to a real Chromium browser so they can explore websites, interact with applications, and complete complex tasks.

Implemented capabilities

Browser operations with verifiable state.

The current small MCP surface publishes three browser tools plus thirteen system tools. Use the runtime tools/list response for the active set.

DISCOVER

Inspect browser capabilities

browser-schema searches operations and returns their argument contracts; for example, discover how to find a form control before interacting with it.

Parameters and example →

EXECUTE

Call browser operations

browser-call executes an ordered batch of semantic operations; for example, read a page and verify visible text.

Parameters and example →

VERIFY

Retain browser events

browser-events subscribes to bounded CDP notifications; for example, observe target lifecycle changes and detect dropped events.

Parameters and example →

ARTIFACTS

Capture browser evidence

screenshot, download, and verify-artifact capture files and verify their integrity after an automation step.

Parameters and example →

WORKFLOWS

Resume guarded routines

call-routine executes reusable workflows; for example, capture a screenshot only after the target passes an assertion.

MCP working example

Discover tools without starting Chromium.

With a running server and a valid local bearer token, call the stateless browser-schema tool using the standard MCP tools/call method. 

curl http://127.0.0.1:8787/mcp \
  -H "Authorization: Bearer $JELLY_MCP_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"browser-schema","arguments":{"action":"capabilities"}}}'

A successful JSON-RPC response includes result.structuredContent.ok: true and result.structuredContent.data.action: "capabilities", with categories and an operation count. Permission: bearer token or OAuth jelly scope. Limitation: this verifies MCP discovery, not browser readiness.

Quickstart

Try Jelly.

Check your Linux prerequisites, preview the configuration, then run the interactive installer. The wizard configures authentication, hosting, and managed services.

jelly / quickstart 
$ git clone https://github.com/FabioFlorey/jelly.git
$ cd jelly
$ ./scripts/dev.sh doctor

# preview setup without changing services or secrets
$ ./scripts/dev.sh setup --dry-run

# run the interactive setup
$ ./scripts/dev.sh setup

For hosting, credentials, and the first MCP request, follow the step-by-step installation guide.
