ChatGPT connection

Choose a remote hosting mode in ./scripts/dev.sh setup to establish an HTTPS endpoint. The ChatGPT profile uses OAuth. Once the server is available, enter the MCP URL in your ChatGPT connection settings and complete the authorization flow.

For hosting and the local approval flow, follow the OAuth setup guide.

Local MCP connection

Configure your Streamable HTTP MCP client with the endpoint and authorization below.

SettingValue
Endpointhttp://127.0.0.1:8787/mcp
AuthenticationAuthorization: Bearer <JELLY_MCP_TOKEN>
TransportStreamable HTTP

For a complete authenticated request, see the MCP example.

Rust CLI

Run these commands on a dedicated Jelly browser or while other workflows are idle. Opening a URL changes the shared browser page:

cargo run --quiet --bin agent-run -- open-browser https://example.com
cargo run --quiet --bin agent-run -- read-page

close-browser stops the shared browser for all connected clients.

Discover browser operations:

cargo run --quiet --bin agent-discover -- capabilities
